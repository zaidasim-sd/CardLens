## 2. What the current service does

The prototype captures or accepts an image, sends it through a backend to configured OCR providers, suggests fields, checks local duplicates and stores a reviewed record in the current browser when submitted. Google Cloud Vision is intended as primary and OCR.space as fallback, subject to confirmed deployment configuration. Manual entry and the prepared demo bypass external OCR.

The present service has no application accounts, user roles, central shared contact database, separate manager approval or working Constant Contact connection. The review queue masks information visually; it does not anonymise the underlying record. The current Export Contacts button is not connected to an export action. No feature, integration or security control is supplied merely because a label, environment setting or unused helper refers to it.
