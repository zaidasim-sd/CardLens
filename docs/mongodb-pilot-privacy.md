If the Sheet write fails, the form keeps checked fields for retry, reports an error, and discards its image. There is no server-side contact queue. Image request buffers are cleared when OCR finishes or fails; browser previews are revoked after successful submission, failure, cancellation, or navigation.

The backend checks the Firebase ID token through the configured project's Authentication API, requires verified email, and matches the Firebase UID to the Mongo approval record. Browser email claims cannot authenticate a Google user. New verified accounts remain pending approval. MongoDB password provisioning is disabled, and legacy sessions without a linked Firebase UID are refused. Verification and password reset use Firebase email links.
